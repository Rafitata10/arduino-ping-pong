# Arduino Pong

Classic **PONG game** running on an Arduino Nano with an SSD1306 OLED display.

## Hardware

- Arduino Nano (ATmega328P)
- SSD1306 OLED 128x64 (I2C)
- 2 Potentiometers
- Push Button
- Passive Buzzer

## Controls

- Player A → Potentiometer A0
- Player B → Potentiometer A1
- Button → Start / Pause
- Buzzer → Sound effects

## Libraries

- Adafruit GFX
- Adafruit SSD1306
